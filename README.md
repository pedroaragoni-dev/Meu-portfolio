# 💼 Portfólio Pessoal

Projeto desenvolvido durante meus estudos de **HTML5, CSS3 e JavaScript**, com base nos conhecimentos adquiridos no **Curso em Vídeo**, ministrado pelo professor Gustavo Guanabara.

O objetivo foi criar um portfólio pessoal responsivo para apresentar minha formação, habilidades, projetos e informações de contato.

---

## 📖 Sobre o projeto

Este projeto foi desenvolvido como parte da minha evolução em desenvolvimento web. Além de acompanhar o conteúdo do curso, realizei adaptações e personalizações para representar melhor meu perfil e consolidar os conceitos estudados.

O site reúne informações sobre minha trajetória acadêmica, projetos desenvolvidos e formas de contato, servindo como uma apresentação profissional.

---

## ✨ Funcionalidades

- ✅ Apresentação pessoal
- ✅ Formação acadêmica
- ✅ Seção de projetos
- ✅ Links para redes sociais
- ✅ Vídeo de apresentação
- ✅ Layout responsivo
- ✅ Modo claro e escuro
